Комплексна аналітична система часових рядів та інтерактивний Telegram-бот для моніторингу і короткострокового ймовірнісного прогнозування повітряних тривог в Україні з дискретизацією 15 хвилин, повним поділом на райони для всіх областей, системою раннього попередження (тривога в сусідніх районах), відстеженням векторів руху ударних БпЛА (Neptun/Dimap) та генерацією тактичних візуальних карт небезпеки.

## 📌 Основні можливості

### 1. 📡 Мультиджерельна оперативна синхронізація (Multi-Source Fusion)
* **[alerts.in.ua](https://alerts.in.ua/):** Офіційний золотий стандарт оперативних сповіщень ДСНС та ОВА.
* **[neptun.in.ua](https://neptun.in.ua/):** Тактичний радар повітряних цілей — надає точні GPS-координати, вектори руху (курс у градусах) та трейл польоту БпЛА.
* **[dimap.live](https://dimap.live/):** Дворівнева радарна класифікація (🔴 Червоний — ракети/удар, 🟡 Жовтий — дрони/підвищена готовність).
* **OSINT-моніторинг:** Канали командування **Повітряних Сил ЗСУ** ([@kpszsu](https://t.me/kpszsu)), **War Monitor** ([@war_monitor](https://t.me/war_monitor)) та **Ракета Тревога** ([@raketa_trevoga](https://t.me/raketa_trevoga)).

### 2. 🏘 Повний розподіл на райони для всіх 26 областей
* **Вибір конкретного району:** При виборі області бот відкриває список усіх її районів.
* **Аналіз оточення:** Бот перевіряє статус не тільки вибраного району, а й усіх **сусідніх районів** на основі точного топологічного графа суміжності 137 районів (`data/raion_neighbors.json`).
* **Точний облік кількості БпЛА (1 дрон чи група):** Ймовірність калібрується за масштабом загрози (для одиночного транзитного дрона на заході України ймовірність затягування тривоги на 2 години складає <10%, тоді як для ешелонованої хвилі — 50–70%).

### 3. 🔔 Цілодобове слідкування та раннє попередження (`/track`)
* Користувач може обрати один або декілька районів для спостереження.
* Автоматичний фоновий демон здійснює раннє попередження:
  * ⚠️ **Тривога в сусідніх районах:** бот завчасно (за 10–25 хв) попереджає про наближення лінії небезпеки.
  * 🛸 **Підліт ударних БпЛА:** фіксація курсу цілі у бік вашого району за даними радарів.
  * 🔴 **Оголошення тривоги безпосередньо у вашому районі.**
  * Захист від спаму: вбудований автоматичний кулдаун повторних сповіщень.

### 4. 🗺 Тактична візуальна карта повітряних загроз (`/map`)
* Рендеринг тактичної темної мапи України високої роздільності з усіма 137 районами:
  * 🔴 **Червоні райони:** ракетна загроза / активний обстріл.
  * 🟡 **Жовті райони:** загроза БпЛА / підвищена готовність.
  * 🛸 **Маркери цілей:** точні GPS-координати виявлених ударних дронів із зазначенням кількості цілей.
  * ➡️ **Пунктирні вектори екстраполяції:** прогноз положення дронів на обраний горизонт (+15 хв, +30 хв, +1 год, +2 год) зі швидкістю ~180 км/год.
  * 🟦 **Виділення контуру:** контур району, що цікавить користувача.

### 5. 📊 Порівняльні метрики джерел (`/metrics` / `/benchmark`)
* Розрахований індекс Жаккара (Jaccard Similarity) між джерелами:
  * `neptun.in.ua` vs `alerts.in.ua`: **79.25%**
  * `dimap.live` vs `alerts.in.ua`: **61.97%**
* Докладний звіт збережено у `reports/sources_benchmark_report.md`.

### 4. 🧠 Машинне навчання та Feature Engineering без Lookahead Bias
* **Часова сітка:** 15-хвилинні інтервали.
* **Календарні циклічні ознаки:** $\sin/\cos$ перетворення для години доби та дня тижня.
* **Лаги тривог:** Історичний факт тривоги за попередні 1, 3, 6 та 24 години.
* **Ковзні вікна:** Середня тривалість тривог за останні 7 днів виключно на основі даних, відомих *до* початку цільового слота (`shift(1)` / `closed='left'`).
* **Моделі:** Градієнтний бустинг (LightGBM) у порівнянні з наївним бейслайном.
* **Метрики:** Оптимізація PR-AUC (Precision-Recall AUC), Brier Score та F1-score за зваженим порогом.

## 🚀 Швидкий запуск

### 1. Клонування репозиторію та налаштування оточення
```bash
git clone https://github.com/Zetron43/Time-Series-Analysis-of-air-raid-alerts-in-Ukraine.git
cd Time-Series-Analysis-of-air-raid-alerts-in-Ukraine

# Створення та активація віртуального середовища
python -m venv .venv

# Для Linux / macOS:
source .venv/bin/activate

# Для Windows PowerShell:
.\.venv\Scripts\Activate.ps1

# Встановлення залежностей
pip install -r requirements.txt
```

### 2. Налаштування токена Telegram Bot
Створіть файл `.env` у корені проєкту (за зразком `.env.example`):
```env
TELEGRAM_BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
```

### 3. Запуск бота в режимі Live
```bash
python bot.py
```

### 4. Запуск симуляції діалогу в консолі (без токена)
Ви можете протестувати відповіді бота для будь-якої області безпосередньо у терміналі:
```bash
# Симуляція для Сумської області на горизонт 1 година:
python bot.py --simulate sumy 1h

# Симуляція для АР Крим на горизонт 15 хвилин:
python bot.py --simulate crimea 15m

python bot.py --simulate dnipro 30m
```

## 📊 Машинне навчання та наукова методологія

### Запобігання витоку даних (Lookahead Bias Prevention)
При побудові ознак для часового слота $T$:
* Значення індикатора тривоги береться виключно за попередні періоди:
  $$\text{Lag}_k(T) = \text{Alert}(T - k \cdot 15\text{ хв})$$
* Ковзні середні тривалості тривог за 7 днів розраховуються із закритим зліва вікном (`closed='left'`).
* Будь-які текстові повідомлення ПС ЗСУ синхронізуються за часовою міткою публікації: новина, опублікована о `14:02`, не може вплинути на прогноз для інтервалу `14:00`.

### Метрики ефективності
Через високий дисбаланс класів класична метрика *Accuracy* не застосовується. Використовуються:
1. **PR-AUC (Precision-Recall Area Under Curve):** Головна оцінка якості виявлення тривог.
2. **Brier Score:** Оцінка калібрування ймовірностей прогнозу.
3. **F1-score:** За оптимального порогу відсікання ймовірності.
